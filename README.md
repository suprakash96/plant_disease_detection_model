

Smart Agriculture – Plant Disease Detection Using Leaf Image Processing

 Project Description

Smart Agriculture is a Python-based machine learning project that detects plant diseases from leaf images using image processing and deep learning techniques.

The project uses a Convolutional Neural Network (CNN) to analyze uploaded plant leaf images and classify them into different disease categories. It helps identify possible plant diseases at an early stage and supports smarter agricultural practices.

The system is developed using Python and runs on Google Colab.

 Objectives

- Detect plant diseases using leaf images.
- Apply image processing techniques to prepare images.
- Train a CNN model for disease classification.
- Predict disease categories from uploaded images.
- Display prediction confidence.
- Support smart and efficient agricultural practices.

Technologies Used

- Python
- Google Colab
- TensorFlow
- Keras
- NumPy
- Matplotlib
- OpenCV
- CNN (Convolutional Neural Network)

Dataset

PlantVillage Dataset

The PlantVillage dataset contains images of healthy and diseased plant leaves belonging to different plant species.

Dataset: [https://www.kaggle.com/datasets/emmarex/plantdisease](https://www.kaggle.com/datasets/emmarex/plantdisease)

Project Features

1. Plant leaf image uploading.
2. Image resizing and preprocessing.
3. CNN-based model training.
4. Automatic plant disease classification.
5. Prediction confidence percentage.
6. Training accuracy and loss visualization.
7. Trained model saving and downloading.

How to Run the Project

1. Download or clone this repository.
2. Open Google Colab.
3. Upload the `.ipynb` notebook.
4. Download the PlantVillage dataset.
5. Upload your Kaggle API key (`kaggle.json`) when requested.
6. Run all notebook cells in sequence.
7. Train the CNN model.
8. Upload a plant leaf image to predict its disease.

Expected Output

The system displays:

- Uploaded plant leaf image.
- Predicted disease name.
- Prediction confidence percentage.
- Top 5 possible disease categories.
