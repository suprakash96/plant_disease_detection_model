Requirements – Smart Agriculture: Plant Disease Detection
1. Hardware Requirements
- Computer or Laptop
- Minimum 4 GB RAM (8 GB recommended)
- Intel Core i3 processor or higher
- Stable internet connection
- GPU (optional, recommended for faster training)
2. Software Requirements
- Operating System: Windows / Linux / macOS
- Python 3.x
- Google Colab
- Google Chrome or any modern web browser
- Kaggle Account (for dataset download)
3. Python Libraries
The following libraries are required:
Library	Purpose
TensorFlow	CNN model development and training
Keras	Deep learning
NumPy	Numerical calculations
Matplotlib	Image and graph visualization
OpenCV	Image processing
Pillow (PIL)	Image loading and resizing
OS	File and directory management

4. Dataset Requirements
- PlantVillage dataset
- Healthy plant leaf images
- Diseased plant leaf images
- Images in JPG, JPEG or PNG format
- Separate folders for different disease categories
5. Functional Requirements
1. Upload plant leaf images.
2. Preprocess and resize images.
3. Train the CNN model.
4. Detect plant diseases.
5. Display the predicted disease name.
6. Display prediction confidence.
7. Save the trained model.
6. Non-Functional Requirements
1. Easy-to-use interface.
2. Fast image processing.
3. Reliable prediction results.
4. Efficient model training.
5. Compatibility with Google Colab.
